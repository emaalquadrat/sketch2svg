**De l'esbós al vector.** Fes una foto d'un dibuix fet a mà i converteix-lo en un fitxer per a la talladora làser, el plotter, la brodadora o un programa de modelat 3D. Funciona sense internet i no cal instal·lar res més.

## Quin fitxer descarrego?

| El teu ordinador | Descarrega |
|---|---|
| **Windows** | `Sketch2SVG-…-Windows.exe` |
| **Ubuntu, Linkat o Debian** | `sketch2svg_…_amd64.deb` |
| **Un altre Linux** | `Sketch2SVG-…-Linux` |

### Windows

1. Descarrega `Sketch2SVG-…-Windows.exe` i fes-hi doble clic.
2. El primer cop, Windows pot mostrar l'avís blau **«Windows ha protegit l'ordinador»**. Surt amb tots els programes petits que no paguen una signatura digital. Prem **Més informació** i després **Executa igualment**.
3. Pot trigar uns segons a obrir-se: és normal, el programa ho porta tot a dins.

### Ubuntu, Linkat o Debian

1. Descarrega `sketch2svg_…_amd64.deb` i fes-hi doble clic. S'obrirà el programa d'instal·lació d'aplicacions: prem **Instal·la**.
2. Després el trobaràs al menú d'aplicacions com a **Sketch2SVG**.

Si el doble clic no obre l'instal·lador, fes clic dret al fitxer → **Obre amb** → **Instal·lació de programari**. O bé, des d'una terminal a la carpeta de baixades: `sudo apt install ./sketch2svg_*_amd64.deb`

### Un altre Linux

1. Descarrega `Sketch2SVG-…-Linux`.
2. Clic dret → **Propietats** → **Permisos** → marca **Permet executar el fitxer com un programa**. Només cal fer-ho el primer cop.
3. Fes-hi doble clic.

## Com es fa servir

Fes una foto de cada esbós amb bona llum, posa-les totes en una carpeta, obre Sketch2SVG, tria la carpeta i el perfil d'ús (dibuix, tall làser, gravat làser o brodat) i prem **Exporta**. Tens més explicacions i consells al [README](https://github.com/emaalquadrat/sketch2svg#readme).

Si el fas servir a l'aula, ens agradarà saber-ho: [emaalquadrat.cat](https://emaalquadrat.cat).
